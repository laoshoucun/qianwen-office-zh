## 千问办公介绍

千问办公（QwenWork）是阿里巴巴推出的一站式 AI 办公智能体平台，深度打通钉钉生态，整合多款阿里智能体能力，覆盖桌面端、网页端多终端使用场景。依托通义千问大模型，主打对话即交付：用户输入自然语言指令，就可完成 PPT、表格、文档、数据分析、网页搭建等任务，直接产出可用成品。内置行业套件，支持多模态解析、跨平台数据聚合，兼顾个人办公提效与企业团队协同，实现任务全流程闭环，无需频繁切换各类工具，大幅降低重复办公工作量。

## 千问办公特点

- 对话即交付模式，一键输出 PPT、文档等成品文件。
- 百万级超长上下文，多模态图文音视频解析能力。
- 桌面云端双智能体，任务后台运行不中断执行。
- 内置多行业办公套件，覆盖电商、财税、HR 等岗位场景。
- 深度接入钉钉生态，企业协同链路闭环打通。
